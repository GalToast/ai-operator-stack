Then read:

2. `opencode-fork` for AI coding workbench systems: task DAGs, semantic retrieval, TUI proof artifacts, and stateful agent runtime.
3. `mccullough-search` for semantic search, with the [semantic-demo](https://github.com/GalToast/semantic-demo) visual companion for frontend presentation.

6. `permit-intelligence-dashboard` for public-record analytics with human review.

I am claiming AI-native operating competence:
